# ParkSave - Smart Parking App

A smart parking mobile application that helps users find, reserve, and track parking slots in real-time. No more circling around looking for parking.

Developed by: *Irish Dalmasi*
Section: *BSINTE 2-A*

## Features

- *Real-time Parking Slots* - View available parking slots in Plaza and other areas
- *Add Slot* - Add a new parking slot to the system
- *Find My Car* - Quickly locate where you parked your car
- *Reserve a Slot* - Reserve a parking slot before you arrive
- *Parking History* - View your past parking records
- *Mobile-Friendly Design* - Works smoothly on phone and desktop
